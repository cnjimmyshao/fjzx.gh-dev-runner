# fjzx.gh-dev-runner

轻量、可部署在不同执行电脑上的 GitHub Issue 接单与 DeepSeek Harness 会话续接工具。

**当前阶段：建立工作与需求基线，尚无可运行程序。** 本仓库没有安装、启动、轮询或接管任何真实任务；示例命令不是已上线功能。

## 目标

一个本地接单程序服务多个明确接入的仓库。它增量检查授权人的评论命令，按执行电脑路由，创建或续接相应 Harness 会话。实际需求分析、编码、测试与 PR 交付由 Dev 遵循目标项目的文档完成。常驻 Harness 的原 Web 界面用于观察工作过程。

不依赖 GitHub Actions 定时轮询，不建设新的审查系统、中央调度平台或管理界面。

## 从哪里开始

- [AGENTS.md](AGENTS.md)：角色、权限、开发与 Review 方法、决策交接。
- [文档导航](docs/README.md)：Current、ADR、Research 与 Archive 的分工。
- [当前需求](docs/current/README.md)：已确认目标、边界与尚未落实的部分。
- [开发环境与验证](docs/development.md)：先做环境验证，再实现最小闭环。

开发入口是关联 Issue。Issue 保存问题与决定，PR 交付变更；读取仓库规则后按任务执行，不依赖聊天里另发一份长提示词。当前没有 package.json、安装脚本、运行命令或自动 Review 配置，不能据此声称环境已就绪。

## 公开仓库与本机数据

示例仅使用占位信息。凭证、真实仓库接入清单、机器路径、任务绑定、会话历史与原始日志留在本机，不上传到本仓库或公开评论。`.local/` 可用于尚未形成正式配置格式前的本机材料，已加入忽略规则；`.gitignore` 不替代提交前的内容检查。
